# Мастерская

Веб-приложение для закупок, материалов, изделий и расчёта себестоимости небольшого производства.

## Что работает (версия 6)

- Закупки с количеством, ценой и распределением доставки.
- Каталог материалов и категории с возможностью редактирования.
- Изделия, направления и рецептуры с несколькими материалами.
- Расход **в граммах, килограммах, миллилитрах, литрах, каплях и процентах** от заданной массы/объёма изделия.
- Пересчёт рецептуры на партию (в штуках готового изделия) с количеством ингредиентов и стоимостью.
- По умолчанию **1 мл эфирного масла ≈ 30 капель**, коэффициент настраивается у конкретного материала.
- Оплата работы, калькуляция себестоимости, цены продажи и прогнозируемой прибыли.
- Просмотр сохранённых калькуляций с зафиксированным составом партии; экспорт/импорт JSON.

Для расчёта в процентах укажите массу или объём одного готового изделия и выберите «%» для соответствующих компонентов. Программа **не переводит граммы в миллилитры без плотности** и не проверяет безопасность косметических рецептур. Пустые или частичные процентные формулы требуют дополнительной проверки.

## Где работает

GitHub Pages: https://vimanadaily.github.io/-masterskaya-app/

**Пока это локальный прототип:** все данные хранятся в браузере конкретного устройства. Для переноса данных между адресами/устройствами используйте **Настройки → Скачать копию JSON**, затем импорт в новом месте. Перед обновлениями сохраните резервную копию. Не загружайте в GitHub свои реальные экспортные файлы, чеки или персональные данные.

Архитектурные заметки для будущей серверной версии: [docs/architecture.md](docs/architecture.md).

## Что ещё не реализовано

Полноценный складской учёт, фиксация выпуска, продажи, личные кабинеты, синхронизация устройств, платежи и подписки. GitHub Pages не предоставляет серверную базу данных и защиту личных кабинетов.
