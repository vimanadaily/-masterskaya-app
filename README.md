# Мастерская

Веб-приложение для учёта закупок, материалов, изделий, рецептур, работы и плановой себестоимости.

**Статус:** рабочий прототип (версия 5). Пока без серверной базы, личных кабинетов и синхронизации устройств.

## Как пользоваться

Откройте опубликованный сайт, добавьте материалы и закупки, создайте изделия и сохраните калькуляции.

Данные хранятся **локально в браузере на конкретном сайте и устройстве**.
Другой браузер, компьютер или домен не получит их автоматически.
Сохраняйте резервную копию в разделе «Настройки» → «Скачать копию JSON».
Для переноса из предыдущей HTML-версии импортируйте JSON-копию на новом сайте.

Не публикуйте в репозитории свои JSON-копии, чеки, персональные и финансовые данные.

## Публикация на GitHub Pages

1. Создайте отдельный репозиторий `-masterskaya-app` в GitHub.
2. Загрузите файлы этого проекта в корень ветки `main` (в том числе `index.html`).
3. Откройте **Settings → Pages → Build and deployment**.
4. Укажите **Deploy from a branch**, ветку **main**, каталог **/(root)** и сохраните.
5. Адрес сайта будет `https://vimanadaily.github.io/-masterskaya-app/`.

### Обновления

Обновите `index.html` в ветке `main`. GitHub Pages опубликует новую версию.
Сначала скачайте JSON-копию данных. При сохранении данных под тем же адресом браузера
их обычно не приходится переносить после обновления сайта.

## Ограничения

- Приложение рассчитывает предварительную себестоимость и прогноз прибыли.
- Полноценные складские списания, продажи и фактическая прибыль ещё не реализованы.
- GitHub Pages не предоставляет серверную базу, регистрацию пользователей и платные тарифы.
- Сайт открыт всем по ссылке. Для конфиденциальных коммерческих данных требуется отдельный серверный продукт.
